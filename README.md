# IMDb Movie Scraper

This project is a bot for scraping movie data from IMDb's Advanced Title Search. It allows you to collect movie titles, release years, ratings, genres, and save the results into a SQLite database and an Excel file.

## 🔍 Features

- Queries IMDb with customizable parameters
- Parses movie listings (title, year, rating, genre)
- Saves results to a local SQLite database
- Exports results to Excel for easy viewing

## 📦 Required Libraries

To run this project, you need to install the following Python libraries:
requests beautifulsoup4 pandas openpyxl selenium selenium-stealth

This can be done in the ternminal with the command:
pip install requests beautifulsoup4 pandas openpyxl selenium selenium-stealth
